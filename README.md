Tolgee Translation Provider
============================

Provides Tolgee integration for Symfony Translation.

DSN example
-----------

```
// .env file
TOLGEE_DSN=tolgee://API_TOKEN@default
TOLGEE_DSN=tolgee://API_TOKEN@app.tolgee.example.com
```

where:
 - `API_TOKEN` is your Project Personal Access API Token

[Generate Personal Access Token on Tolgee](https://tolgee.io/docs/platform/managing_api_keys)
